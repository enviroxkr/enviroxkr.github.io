MISSION
산업현장의 오염 문제를 기술 기반 환경설비로 해결하고, 지속가능한 산업환경을 구축한다.
VISION
국내 환경설비 제작 전문기업을 넘어 RTO·집진·이송·수처리 플랜트 분야 Top-tier 기업으로 성장한다.
CORE VALUE
기술 중심 · 현장 중심 · 신뢰 중심 · 환경 중심의 4대 핵심가치를 기반으로 운영합니다.
